      About Image Inspector

      Image Inspector reads the metadata stored inside an image file. It runs entirely in your browser: the file is never uploaded, and the page keeps working with your network turned off.

      What it reads

      EXIF and maker notes, XMP, IPTC, ICC profiles, Photoshop resources, PNG text, HEIF items and Content Credentials (C2PA). Fields it cannot decode are listed, not dropped.

      What it flags

      GPS location, serial numbers, names, embedded thumbnails, hidden images and layers, editor file paths, and scripts or external links in SVG files.

      AI provenance

      Declarations such as IPTC digital source type, Content Credentials and generator settings. It reports what the file states and never labels an image as AI-generated or authentic.

      Limitations

      • Metadata can be edited or removed, and most platforms strip it on upload. A file with no metadata proves nothing about its origin.
      • Content Credentials signatures are not verified. Invisible watermarks such as SynthID cannot be detected from metadata.
      • Vendor maker notes show identifying fields by name and other entries by tag ID. Brotli-compressed JPEG XL boxes are listed without their contents.
