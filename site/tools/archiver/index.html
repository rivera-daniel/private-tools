        About Archiver

        Archiver packs files and folders into archives and unpacks them, entirely in your browser. Files are read from your disk and written back to it. Nothing is uploaded, and the page keeps working with your network turned off.

        Formats

        Create ZIP, 7z, tar, tar.gz and gzip. Open ZIP (including ZIP64, AES and legacy encrypted entries), 7z, RAR, tar with any compression, gzip, xz, bzip2, zstd, lzma, ISO 9660, CAB, cpio and ar. Large archives are streamed rather than held in memory where the browser can write to disk.

        Passwords

        Password-protected ZIPs use WinZip AES-256 with an authentication code, so a wrong password or altered data is detected. AES-256 encrypted 7z archives open with their password, including ones that hide their file names. Legacy ZipCrypto archives can be opened but never created, because that scheme is broken.

        Remove hidden data

        With this on, every file the Metadata Cleaner supports is cleaned before it is added, and the rest are listed. Entries never carry an owner, comments, extra timestamps or extra fields, and with Hide file dates every date is 1 January 1980.

        Limitations

        • Chrome and Edge can save archives of any size straight to disk. Firefox and Safari keep the output in memory, which limits archives to roughly 2 GB.
        • AES-encrypted ZIPs open in 7-Zip, Keka, The Unarchiver, WinZip and this page, but not in Windows Explorer or macOS Archive Utility. File names inside an encrypted ZIP are not hidden.
        • Files that the Metadata Cleaner cannot read are added unchanged and listed after the archive is created. Files over 200 MB are not cleaned.
        • Archives that expand more than 1,000 times their size are stopped, as are entries that would land outside the chosen folder. Links inside archives are listed but never extracted.
        • Extract to folder puts the files in a new folder named after the archive. Extracting directly into the chosen folder lists every name that already exists there first. Existing files are skipped or kept beside the new ones, and replaced only when you choose Replace. A file that fails to extract never removes one that was already there.
        • 7z, RAR, ISO, CAB and the compressed formats other than gzip are read by libarchive, compiled to WebAssembly and loaded from this site. Encrypted RAR archives cannot be opened, and RAR archives cannot be created. Encrypted 7z archives that combine AES with the BCJ2 filter are not supported.
        • 7z archives are limited to 1 GB of files when creating, because the compressed data stays in memory until the archive is finished. 7z archives cannot be given a password here.
