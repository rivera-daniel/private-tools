      About File Inspector

      File Inspector reads any file and reports what it reveals beyond its visible content. It runs entirely in your browser: the file is never uploaded, and the page keeps working with your network turned off.

      What it reads

      The true file type from its content, format metadata, program headers, version information and signatures, data hidden after the end of the file, files embedded inside it, and readable text anywhere in it.

      What it flags

      Names, email addresses, user names in file paths, network shares and internal host names, hardware addresses, possible secrets and private keys, hidden or look-alike characters in text, and files whose name hides their type.

      What it does not do

      It never runs, opens or decompresses programs and archives. It reports what the bytes contain and does not judge whether a file is safe.

      Limitations

      • Text is searched in the first 24 MB and the last 8 MB of large files. Compressed or encrypted data cannot be searched.
      • Detected email addresses, paths, phone numbers and secrets are patterns, so some may be missed and a few may be false matches.
      • Signatures on programs and certificates are read but not verified. Programs and unknown formats are inspected only and cannot be cleaned.
