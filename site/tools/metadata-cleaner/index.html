Metadata Cleaner

Remove location, camera details, names, AI prompts and hidden data from your images. The pixels are not touched.

    About Metadata Cleaner

    Metadata Cleaner removes the metadata blocks that Image Inspector finds and copies every other byte unchanged. The image is never decoded or re-encoded, so quality stays the same and the file only gets smaller.

    What it removes

    EXIF with GPS and serial numbers, XMP, IPTC, PNG text such as AI prompts, Content Credentials, thumbnails, comments, Photoshop data and data hidden after the image.

    What it keeps

    The image data, ICC color profiles and the orientation setting, so rotated photos still display upright.

    How it checks

    Every cleaned file is inspected again before you can save it. If metadata remains or the image changed, no file is produced.

    Limitations

    • JPEG, PNG, WebP and GIF are supported. Other formats are refused and never altered.
    • Invisible watermarks such as SynthID are part of the pixels and are not affected.
    • Phone photos can carry an HDR gain map or depth map after the main image. Removing it can make an HDR photo look flatter.

    File tools that run in your browser. Your files are processed on your device and never uploaded. No account required.
